# 一品多商 - 版本更新清单

---

## V1 - 基础原型

初始版本，搭建完整页面框架与核心交互流程。

**项目总览**
- 四张统计卡片（物料总数、已匹配类目、相似匹配完成、技能池）
- 匹配进度趋势折线图（精确/模糊匹配）
- 类目分布饼图
- 客户项目进度（进度条形式）
- 分类准确率横向柱状图
- 最近活动时间线

**数据准备**
- 分栏导航（数据总览/导入记录/校验规则）
- 物料数据表格（8条数据），支持搜索、分页
- 统计卡片（物料总数/数据完整/待补充/异常数据）

**类目匹配**（独立页面）
- 类目自动映射与人工校验界面

**相似匹配**
- 流程提示条（建议→确认→锁定→导出）
- 统计卡片（匹配组/精确匹配/待确认/已确认/已驳回）
- 匹配组列表，展开显示匹配商品
- 单条确认/驳回/调整/查看详情
- 导出 CSV、启动匹配

**规则配置**
- Skills Engine 架构，客户列表+技能池
- 5种 Skill 类型（提示词/匹配规则/权重配置/数据补全/特殊规则）
- Skill 的创建/编辑/复制/删除/启停
- 类目筛选与批量类目配置

**BadCase / 数据核查**
- BadCase 标注与归因分析
- 数据核查报告

---

## V2 - 数据丰富与交互增强

在 V1 基础上大幅扩充数据量，增强图表交互，优化细节。

**项目总览**
- 趋势图升级：标题改为"一级类目匹配准确率趋势"，增加版本发布标记线（V1/V2）
- 客户项目进度：新增物料数/一二三级类目数量展示，流程步骤条替代进度条

**数据准备**
- 物料数据从 8 条扩充至 125 条（含 13 页分页）
- 新增列：SKU_NO、名称、品牌、型号
- 统计卡片数据更新（125/5/102/18）
- 新增管理员租户切换功能
- 新增标准类目树预览（可折叠/搜索/层级展开）
- 一级类目按钮显示三级类目数量
- 新增数据状态筛选（全部/完整数据/待补充/异常数据）
- 分页器升级：首尾页/跳页输入

**类目匹配**
- 页面保留但侧边栏入口已移除（功能合并至相似匹配）

**相似匹配**
- 两张可视化卡片合并为"一级类目匹配概览"（半透明叠放进度+准确度双指示条）
- 匹配组数据从 4 组扩充至 24 组，覆盖 9 个一级类目
- 新增搜索栏 + 类目下拉筛选
- 新增分页器（含首尾页/跳页）
- 底部操作栏（返回数据准备/导出/最终确认锁定）
- 匹配商品表格化展示（供应商/相似度/类型/状态列）

**规则配置**
- 新增"通用归一化提示词"Skill（跨客户共享）
- 类目筛选栏增加类目 chips

## V3 - 多维筛选与批量操作

在 V2 基础上增加分栏导航、批量操作、Excel 导入等协作与效率功能。

**项目总览**
- "已匹配类目" → "已匹配一级类目"，点击跳转从数据准备改为相似匹配页面
- "类目分布" → "三级类目分布"
- "分类准确率" → "一级类目匹配进度"，点击跳转改为相似匹配页面
- 侧边栏移除"类目匹配"入口（页面已删除）

**数据准备**
- 一级类目按钮后显示三级类目计数

**相似匹配** (重大更新)
- 新增分栏导航（数据总览 / 操作记录 / 匹配规则）
- 流程提示条从独立一行移至标题右侧紧凑展示
- "全部确认"按钮移到"N 待确认"文字旁边
- 新增标准类目树预览（从数据准备复制），支持折叠/搜索
- 类目树支持点击一/二/三级类目自动筛选下方数据，选中高亮，再次点击取消
- 类目树标题显示当前筛选类目 Badge（可点击清除）
- 新增状态快速筛选按钮（全部/待确认/已确认/已驳回）+ 各状态计数
- 新增管理员租户快速切换
- 主商品支持多选（全选当页），选中后可批量确认/驳回
- 匹配商品支持多选（组内全选），选中后可批量确认/驳回
- 顶部显示全局已选匹配商品数 + 批量操作按钮
- 操作记录 tab：展示完整操作日志（批量确认/手动调整/匹配完成/启动匹配/驳回/规则更新/导出等）
- 匹配规则 tab：展示当前生效的匹配规则列表，支持跳转至规则配置管理

**规则配置**
- 匹配规则编辑器新增 Excel 上传快速配置（解析阈值/维度/模式/跨类目设置）
- 权重配置编辑器新增 Excel 上传快速配置（解析权重分配 + 加速因子）
- 两种类型均支持下载当前配置为 Excel 模板
- 新增类目 chips 筛选栏（紧固件/电气电工/劳保防护等）
